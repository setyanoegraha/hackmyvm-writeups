A personal collection of cybersecurity writeups documenting my journey through various HackMyVM machines and Venus lab challenges.

## 📋 Overview

This repository serves as a comprehensive documentation of penetration testing exercises, privilege escalation techniques, and security challenges completed on the HackMyVM platform. Each writeup provides detailed walkthroughs, methodology, and technical insights gained during the exploitation process.
